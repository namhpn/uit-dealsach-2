# T0031 — ProductDetail Hero Action Button Alignment Fix

## Goal

Make the `Thêm vào Wishlist` and `THEO DÕI GIẢM GIÁ` hero buttons on `ProductDetailPage` visually consistent and correctly aligned with the best-price card.

## Dependencies

* T0030, after it is completed or merged.

## Allowed areas

* `frontend/src/app/pages/ProductDetailPage.tsx`
* `docs/Tickets.md`
* `docs/Manual_Verification_Guide.md`
* `docs/Repo_Current_State.md`
* `docs/Known_Issues_And_Followups.md`
* `docs/implementation_logs/T0031.md`

## Do not touch

* `docs/frontend/frontend-req.md`
* `docs/frontend/design-system.md`
* Backend files
* API contracts
* Seed data
* Buy-flow behavior
* Alert API behavior
* Seller offer row behavior
* Homepage/Search/Wishlist/Alerts/Admin pages

## Requirements

1. Keep the current hero price card content unchanged:

   * best current price/status;
   * reference/strikethrough price behavior;
   * compact `PriceDisclaimer`.

2. In `HeroSection`, standardize the visual treatment of:

   * `Thêm vào Wishlist` / `Đã lưu`;
   * `THEO DÕI GIẢM GIÁ`.

3. Both hero action controls must have the same:

   * height;
   * width;
   * icon/text alignment;
   * font family;
   * font size;
   * font weight;
   * uppercase rhythm;
   * border treatment;
   * shadow treatment;
   * horizontal padding.

4. Preserve behavior:

   * Wishlist remains a button and still calls `onToggleWishlist`.
   * Guest wishlist click still triggers the existing auth flow.
   * Registered-user wishlist click still toggles saved state.
   * Price-alert action remains an internal link to `#price-alerts`.
   * Do not make the price-alert hero action create an alert directly.

5. Fix layout alignment:

   * On desktop, the action column should visually align with the best-price card.
   * The two action controls should not appear shorter, lower, or disconnected from the price card.
   * On mobile, the controls should stack below the price card at full width.

6. Use a narrow local fix in `ProductDetailPage.tsx`.

   * Prefer local shared constants/helper styles for these two hero actions.
   * Do not modify global `NbButton` behavior unless absolutely necessary.

7. Do not change public copy in this ticket unless required for layout.

   * Keep `Thêm vào Wishlist`.
   * Keep `Đã lưu`.
   * Keep `THEO DÕI GIẢM GIÁ`.

## Implementation notes

A safe direction is:

```tsx
const HERO_ACTION_CLASS =
  "inline-flex h-12 w-full items-center justify-center gap-2 px-4 text-[11px] font-extrabold uppercase";

const heroActionStyle: CSSProperties = {
  border: border2,
  background: C.white,
  color: C.onSurface,
  fontFamily: FONT,
  fontSize: 11,
  fontWeight: 800,
  minHeight: 48,
  padding: "0 16px",
  boxSizing: "border-box",
};
```

Then apply matching style overrides to `NbButton`, and use the same class/style base for the alert `<a>`. For the layout, change the grid/action column toward:

```tsx
<div className="grid gap-3 lg:grid-cols-[minmax(0,1fr)_280px] lg:items-stretch">
  ...
  <div className="flex h-full flex-col justify-center gap-2 lg:self-stretch">
```

Exact class names can be adjusted, but the result must be equal-sized controls aligned to the price card.

## Acceptance criteria

* `Thêm vào Wishlist` and `THEO DÕI GIẢM GIÁ` appear as same-size hero action controls.
* Their icons and labels align consistently.
* The action column aligns cleanly with the best-price card on desktop.
* Mobile layout remains stacked and full-width.
* Wishlist behavior is unchanged.
* Price-alert anchor still scrolls to `#price-alerts`.
* Product price disclaimer remains visible near the best-price area.
* No backend/API files are changed.
* Frontend build passes.
