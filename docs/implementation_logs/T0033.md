# T0033 — Alert Email URL and Redirect Formatting Fix

## Goal

Fix outbound email formatting and alert email links so email bodies do not wrap unexpectedly, alert emails contain full DealSach URLs from `app.baseURL`, and email deal-link clicks redirect to the public book page on the production domain.

## Dependencies

* T0032 completed.
* Existing alert email implementation in `backend/app/Libraries/AlertNotificationService.php`.
* Existing email-code SMTP delivery implementation in `backend/app/Libraries/EmailVerificationService.php`.
* Existing email link controller in `backend/app/Controllers/AlertEmailLinkController.php`.
* Existing CI4 email config in `backend/app/Config/Email.php`.
* Existing tests in `backend/tests/feature/PriceAlertFeatureTest.php` and `backend/tests/feature/AuthFeatureTest.php`.
* `.codex/skills/diagnostic-protocol/SKILL.md`.
* Production `.env` already has `app.baseURL='https://dealsach.eu.cc/'` per reviewer note.

## Requirements

* Use `.codex/skills/diagnostic-protocol/SKILL.md` before changing code.
* Trace the current path:

  * OTP email body creation → CI4 email config → SMTP `setMessage()`.
  * Alert email body creation → `outbound_emails.body_text` → SMTP `setMessage()`.
  * Alert deal token click → `AlertEmailLinkController::deal()` → `AlertNotificationService::recordDealLinkClick()` → redirect response.
* Disable CI4 automatic word wrapping for outbound emails by changing the email config, not by manually inserting arbitrary line breaks in email bodies.
* Alert email body must include full absolute URLs using `config('App')->baseURL`:

  * `https://dealsach.eu.cc/email/deals/{token}`
  * `https://dealsach.eu.cc/alerts/disable/{token}`
* Do not hard-code `https://dealsach.eu.cc` in service logic; derive it from `app.baseURL`.
* Normalize `app.baseURL` with exactly one slash between base URL and path.
* Keep storing internal `deal_link_path` and `disable_link_path` metadata if useful, but user-visible email text must contain full URLs.
* Email deal-link click redirect must not rely on CI4 inferring `localhost` or `index.php` from a relative redirect.
* Email deal-link click redirect must resolve to:

  * `https://dealsach.eu.cc/book/{bookId}`
* Remove the `#offers` fragment from new email deal-link landing paths.
* Existing stored email deal links with `/book/{bookId}#offers` must still redirect safely to `/book/{bookId}`.
* Preserve click tracking in `email_deal_link_clicks`.
* Preserve invalid-token and disable-token behavior.
* Preserve DealSach product boundary:

  * DealSach does not sell books directly.
  * Email copy must retain reference-price and affiliate disclosure language.
